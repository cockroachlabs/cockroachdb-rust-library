Expand description

Connects to CockroachDB and returns a SeaORM [DatabaseConnection].

The Config’s retry policy is applied by execute_tx; connection-pool tuning beyond the URL should be set via SeaORM’s ConnectOptions using [sea_orm::Database::connect] directly.
