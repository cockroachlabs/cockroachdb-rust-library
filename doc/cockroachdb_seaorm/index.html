SeaORM adapter for CockroachDB.

SeaORM runs on SQLx, so this adapter adds CockroachDB’s serialization-conflict retry (SQLSTATE 40001) around SeaORM transactions and classifies [DbErr] by reaching through to the underlying SQLSTATE (reusing the SQLx adapter’s classifier). Mirrors the Go library’s GORM adapter.

let policy = RetryPolicy::default();
execute_tx(&db, &policy, |txn| Box::pin(async move {
    // ... SeaORM entity operations on `txn`, retried on 40001 ...
    let _ = txn;
    Ok(())
})).await
