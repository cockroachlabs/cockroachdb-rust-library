Module multiregion

Multi-region schema check for SeaORM entities — the driver half.

describe turns a SeaORM entity marked with #[derive(CrdbLocality)] into a MultiregionTable descriptor; verify_multiregion loads the live schema and runs the pure cockroachdb_core::multiregion::evaluate diff. This mirrors the Spring Boot starter’s startup check, on the SeaORM path.

It is opt-in: call verify_multiregion after crate::connect, passing the entities to check. In Mode::Warn (the default) it logs problems and continues; in Mode::Validate, or on a contradiction in any mode but Mode::None, it returns Err so the caller can fail startup.

let report = verify_multiregion(&db, Mode::Warn, vec![describe::<ideas::Entity>()]).await?;
assert!(report.is_empty() || !report.has_contradictions());
