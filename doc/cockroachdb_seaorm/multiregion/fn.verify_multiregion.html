pub async fn verify_multiregion(
    db: &DatabaseConnection,
    mode: Mode,
    tables: Vec<MultiregionTable>,
) -> Result<MultiregionReport, DbErr>
Expand description

Checks tables against the live multi-region schema of db.

Returns an empty report when mode is Mode::None, when tables is empty, or when the database is not CockroachDB (the check skips quietly). Otherwise loads the schema, diffs it, and — if there are problems — either returns Err (validate, or any contradiction) or logs to stderr and returns the report (warn).
