SQLx adapter for CockroachDB — the primary adapter for this library.

Wraps a [sqlx::PgPool] with CockroachDB-aware behaviour:

  • Pool::execute_tx runs a closure in a transaction and retries it on serialization conflicts (SQLSTATE 40001) with exponential backoff.
  • Pool::follower_read_tx / Pool::fetch_all_follower_read run reads against a transaction scoped with AS OF SYSTEM TIME.
  • Isolation level and read-only mode are applied per transaction.
  • The pool implements [cockroachdb_core::HealthChecker].

Re-runnable closures take &mut sqlx::PgConnection and return a boxed future; this works around Rust’s lending-closure limits. A typical call:

pool.execute_tx(|conn| Box::pin(async move {
    sqlx::query("UPDATE accounts SET balance = balance - 100 WHERE id = $1")
        .bind(1_i64)
        .execute(&mut *conn)
        .await?;
    Ok(())
})).await
