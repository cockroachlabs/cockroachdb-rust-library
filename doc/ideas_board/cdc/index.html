CDC track: a changefeed handler that projects row changes into Ideas, and the webhook sink that dispatches CockroachDB deliveries to it.

Structs§

IdeaChangefeedHandler
Projects changefeed row changes into Ideas. Inserts and updates are kept as the new row image; deletes are counted. The library’s EventHandler takes &self and must be Send + Sync, so state lives behind a Mutex — the handler is shared across concurrent webhook deliveries.
