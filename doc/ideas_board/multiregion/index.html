Source
Expand description

Multi-region track: home each idea to a region via the hidden crdb_region column. CockroachDB homes a REGIONAL BY ROW row by the value written to that column on insert — there is no SET crdb_region session statement (a mistake that bit several sibling libraries). This module only ever writes the column value.

Structs§

RegionalIdeaService
Writes ideas homed to a caller-chosen region. The region travels as the row’s crdb_region column value on insert, so CockroachDB stores and serves that row from the matching region. Homing is per-row data — there is no session-level region switch.

regional_setup_sql
DDL that turns the board into a multi-region, REGIONAL BY ROW deployment: declare the database’s regions, then set the table’s locality so every row carries a crdb_region homing column. Run these once per cluster (adding a non-primary region needs nodes in that locality).
