#[transactional]
Expand description

Wraps an async fn body in a retrying transaction.

The annotated function must take the pool as a parameter (named pool by default, or #[transactional(db)] to name a different one) and return Result<T, sqlx::Error>. Inside the body, use the injected conn binding (&mut sqlx::PgConnection) for queries.

ⓘ
#[transactional]
async fn transfer(pool: &Pool, from: i64, to: i64, cents: i64) -> Result<(), sqlx::Error> {
    sqlx::query("UPDATE accounts SET balance = balance - $1 WHERE id = $2")
        .bind(cents).bind(from).execute(&mut *conn).await?;
    sqlx::query("UPDATE accounts SET balance = balance + $1 WHERE id = $2")
        .bind(cents).bind(to).execute(&mut *conn).await?;
    Ok(())
}

Because the body may run more than once (each retry), parameters it uses must be Copy or cloned inside the body — the same constraint as the hand-written closure form.
