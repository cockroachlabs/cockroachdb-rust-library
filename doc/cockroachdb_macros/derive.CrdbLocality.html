Expand description

Declares a SeaORM entity’s multi-region locality, the analogue of Spring’s @GlobalTable / @RegionalByRow / @CrdbRegion.

Put it on the entity’s Model struct alongside DeriveEntityModel; it generates impl cockroachdb_core::multiregion::CrdbLocality for Entity, which the SeaORM adapter’s verify_multiregion check diffs against the live table. Requires a cockroachdb-core dependency (the generated code names it by path).

Container attribute (exactly one required):

  • #[crdb(global)] — the table should be GLOBAL.
  • #[crdb(regional_by_row)] — the table should be REGIONAL BY ROW.

Field attribute (only with regional_by_row):

  • #[crdb(region)] — marks the region column. The declared column name is the field’s name.
ⓘ
#[derive(Clone, Debug, PartialEq, DeriveEntityModel, CrdbLocality)]
#[sea_orm(table_name = "ideas")]
#[crdb(regional_by_row)]
pub struct Model {
    #[sea_orm(primary_key)]
    pub id: i64,
    pub title: String,
    #[crdb(region)]
    pub region: String,
}
