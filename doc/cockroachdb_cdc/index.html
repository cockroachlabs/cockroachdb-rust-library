Change data capture (CDC) for CockroachDB.

Three driver-agnostic pieces mirroring the Go library’s cdc package:

  • ChangefeedSpecBuilder builds a CREATE CHANGEFEED statement — run the resulting SQL with your own pool (this crate stays decoupled from any driver).
  • Envelope / Payload parse the JSON a CockroachDB webhook sink posts.
  • WebhookSink validates optional bearer auth, parses the envelope, and dispatches each row to your EventHandler, recording CdcMetrics.
