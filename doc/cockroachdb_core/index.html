Driver-agnostic core for the CockroachDB Rust library.

This crate mirrors the Go library’s crdbgo package: it has no SQL-driver dependency and defines the types, traits, and pure logic that the SQLx and SeaORM adapters build on — retry policy, SQLSTATE classification, isolation levels, follower-read AS OF SYSTEM TIME builders, multi-region row homing, a circuit breaker, composable middleware, and metrics/health traits.

See cockroachdb-sqlx for the primary adapter that wires these into a connection pool.
