Multi-region row homing for REGIONAL BY ROW tables.

CockroachDB homes a row to a region via its hidden crdb_region column. Homing is done by writing a value to that column on insert — not by a SET crdb_region session statement, which does not exist (a mistake that bit several sibling libraries). These helpers only ever produce column values.
