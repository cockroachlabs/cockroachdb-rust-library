SQLSTATE-based error classification.

CockroachDB reports contention with SQLSTATE 40001 (serialization failure). Adapters implement SqlState for their driver’s error type so the core can decide whether an operation is retryable, mirroring the Go library’s sqlStateError interface and its source-chain unwrapping.
