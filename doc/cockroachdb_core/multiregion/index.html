Multi-region schema check — the pure, driver-agnostic half.

Compares an application’s declared entity locality (#[derive(CrdbLocality)], see cockroachdb-macros) against the live multi-region configuration of its database and tables, and suggests SQL for every difference. It only produces strings; it never touches a connection — the SeaORM adapter loads the live MultiregionState and calls evaluate.

Faithful port of the Spring Boot starter’s MultiregionCheck: same SHOW / information_schema reads (no crdb_internal), same both-directions diff, same contradiction rules. The fix-up SQL is built from the shared crate::ddl builders.

evaluate
Lists every difference between tables and state, with SQL to fix the schema or a description of the marker to fix. tables holds every entity, marked or not: a GLOBAL or REGIONAL BY ROW table needs its marker too.
fails_startup
Whether a non-empty report should fail startup under mode: validate fails on any problem, and a contradiction fails in every mode but none. This is the decision the SeaORM entry point makes — isolated here so it is unit-testable without a database.
