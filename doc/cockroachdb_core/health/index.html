Health-check trait and status.

Mirrors the Go library’s HealthChecker (a pool implements it by pinging the cluster) and HealthStatus ("up" / "down"). This crate is framework-free: the trait and status live here; an HTTP handler can be built on top in an adapter (e.g. with axum).
