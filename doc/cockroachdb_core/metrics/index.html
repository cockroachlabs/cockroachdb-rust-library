Metrics traits and an in-memory recorder.

Mirrors the Go library’s MetricsRecorder interface and Snapshot. The SQLx adapter records transaction outcomes, retries, and follower reads here; the InMemoryRecorder is ideal for tests. An OpenTelemetry recorder can be added as a separate type implementing MetricsRecorder.
