Composable asynchronous middleware around a unit of work.

Rust has no AOP, and its async closures don’t compose as cleanly as Go’s func(next TxFn) TxFn. This module provides the minimal boxed-future equivalent: a TxFn is a runnable unit of work and a Middleware wraps one into another (for timing, logging, circuit breaking, …). The circuit breaker exposes a Middleware via this plumbing.
